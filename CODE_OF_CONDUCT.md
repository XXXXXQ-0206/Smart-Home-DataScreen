# Code of Conduct

## Our Pledge

We are committed to a welcoming, respectful, and harassment-free community for everyone.

## Expected Behavior

- Be respectful and specific in discussions and reviews.
- Assume good intent while addressing technical impact.
- Protect private data and security reports.

## Unacceptable Behavior

Harassment, discrimination, threats, doxxing, abusive language, and publishing private or security-sensitive information are not acceptable.

## Enforcement

Report unacceptable behavior privately to the repository maintainers through GitHub. Maintainers may edit, remove, or reject contributions that violate this code of conduct.
