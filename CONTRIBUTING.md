# Contributing

Thanks for helping improve Smart-Home Data Screen.

## Development

1. Fork the repository and create a focused branch from `dev`.
2. Install dependencies with `npm ci`.
3. Run `npm run lint` and `npm run build` before opening a pull request.
4. Describe API assumptions, manual checks, and security impact in the pull request.

Do not commit tokens, cookies, local paths, private API responses, screenshots containing personal data, or generated `dist/` output. Use the existing API client and keep endpoint changes isolated and documented.

## Pull Requests

Pull requests should have a clear title, a small reviewable scope, and tests or verification evidence appropriate to the change. Maintainers may request changes before merge.
